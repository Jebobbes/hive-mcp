# Review handoff

Reviewer credentials must be delivered only through the platform-designated secure channel. This document is not proof that credentials have been supplied or that review has passed.

Before submission, verify a dedicated Hive account and workspace can sign in without extra setup, complete the requesting platform's OAuth flow, list tools and read product guidance. Record whether social accounts and representative data are real or fixtures. Do not disable security protections on customer accounts.

Suggested checks:

1. Read product guidance and the connected workspace's available operations.
2. Read connected channels, or accurately report the dedicated workspace is empty.
3. Create a content idea or draft only within the isolated workspace and current permissions.
4. Refuse another workspace and any request for provider credentials.
5. Refuse AI self-approval of a separately approved administration action.

Do not publish posts, send messages, activate automations or change billing as part of this verification without a separately authorized exact action. A passing package/schema check is not a passing real-account connection test.
